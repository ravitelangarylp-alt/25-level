सोपानम् ३ sopāna 3

कः - का - किम्kaḥ - kā - kim

ಪ್ರಶ್ನೆಗಳನ್ನು ಕೇಳಲು ಕಲಿಯೋಣLet's learn how to ask questions

ಹಿಂದಿನ ಪಾಠದಲ್ಲಿ अयम्, इयम्, इदम् ಎಂದು ಹೇಳಲು ಕಲಿತೆವು. ಈಗ "ಇವನು ಯಾರು? ಇವಳು ಯಾರು? ಇದು ಏನು?" ಎಂದು ಸಂಸ್ಕೃತದಲ್ಲಿ ಪ್ರಶ್ನೆ ಕೇಳುವುದು ಹೇಗೆಂದು ಕಲಿಯೋಣ! ಬಣ್ಣಗಳನ್ನು ಗಮನಿಸಿ. We learned ayam, iyam, idam earlier. Now let's learn how to ask "Who/What is this?" in Sanskrit! Notice the colours.

🔍 ಪ್ರಶ್ನೆಗಳನ್ನು ಕೇಳುವ ರಹಸ್ಯThe Secret of Asking Questions

इदम् किम्? मस्तकम्। इदं मस्तकम्।
ಇದು ಏನು? ತಲೆ. ಇದು ತಲೆ. What is this? A head. This is a head.
इयम् का, नासिका। इयं नासिका।
ಇದು ಯಾರು/ಏನು? ಮೂಗು. ಇದು ಮೂಗು. What is this? A nose. This is a nose.
अयम् कः, कर्णः। अयं कर्णः।
ಇದು ಯಾರು/ಏನು? ಕಿವಿ. ಇದು ಕಿವಿ. What is this? An ear. This is an ear.
इदं मस्तकम्।
ಇದು ತಲೆ.This is a head.
👦
इयं नासिका।
ಇದು ಮೂಗು.This is a nose.
👃
अयं कर्णः।
ಇದು ಕಿವಿ.This is an ear.
