Just add 'E' to make it Near! Mastering pronouns for This / Here.

1. Observe & Absorb

Notice the magic? Just add 'ए' (E) to the words you already know!

💡 The "Near" Magic Trick:

• सः (Saḥ - Far) ➡️ एषः (Eṣaḥ - Near Male)
• सा (Sā - Far) ➡️ एषा (Eṣā - Near Female)
• तत् (Tat - Far) ➡️ एतत् (Etat - Near Object)

🏆 Pro-Tip Unlocked!

Did you know? Sanskrit has another set of words that mean exactly the same thing (This / Near)!

एषः = अयम्
(Eṣaḥ = Ayam : This Male)
एषा = इयम्
(Eṣā = Iyam : This Female)
एतत् = इदम्
(Etat = Idam : This Object)

You can use them interchangeably!
